# Coadjute

> Coadjute Ltd is a London-based property technology company running a shared network for the UK residential property market. It connects estate agents, conveyancers, mortgage brokers, lenders and consumers through the CRM and case-management systems they already use — the UK has no MLS and no RESO adoption — and is now positioned as a fully managed AML and compliance platform for UK property, built on R3 Corda distributed ledger technology. Its API posture is partner-only: a "Partner Cloud API" exists contractually, but no public specification, portal, SDK or self-serve signup is reachable.

## Status

- Access gate: partner-only. Access requires a signed Coadjute Partner Terms of Service with an Order Form and Subscription Term; API tokens are provisioned by Coadjute staff per partner.
- Public API specification: none. api.coadjute.com is live but authenticates every path including /.well-known/*; developer.coadjute.com (which carried an API Catalogue in 2020-2021) returns HTTP 502; no OpenAPI, AsyncAPI, OData $metadata, Postman collection or SDK could be retrieved.
- Only anonymous machine-readable contract: the Auth0-backed OpenID Connect discovery document at auth.coadjute.com.
- Open data: none. The open UK property-data layer belongs to HM Land Registry and Ordnance Survey, not to Coadjute.

## APIs

- [Partner Cloud API](https://www.coadjute.com/coadjute-network-acceptable-use-policy): Named in Coadjute's Network Acceptable Use Policy alongside an "End User App Plugin". No public documentation, base URL or specification is published; the live gateway host is api.coadjute.com and answers 401/404 JSON envelopes to anonymous callers.

## Identity and access

- [OpenID Connect discovery](https://auth.coadjute.com/.well-known/openid-configuration): Auth0 tenant, issuer https://auth.coadjute.com/.
- [OAuth 2.0 Authorization Server Metadata](https://auth.coadjute.com/.well-known/oauth-authorization-server): RFC 8414 document for the same tenant.
- Grants advertised: authorization_code (PKCE S256), client_credentials, refresh_token, password, implicit, device_code, token-exchange, jwt-bearer. DPoP (ES256), CIBA, back-channel logout and dynamic client registration are advertised.
- Scopes advertised are the standard OIDC identity set (openid, profile, email, phone, address, offline_access and Auth0 claim scopes). No Coadjute product/API scopes are published anywhere public.
